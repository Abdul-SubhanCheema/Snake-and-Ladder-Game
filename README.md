# 🐍 Snake & Ladder Game

![C++](https://img.shields.io/badge/C++-00599C?style=for-the-badge&logo=c%2B%2B&logoColor=white)
![Console](https://img.shields.io/badge/Console-000000?style=for-the-badge&logo=windows-terminal&logoColor=white)

**Classic board game implemented in C++ with file persistence**

## 🎮 Features
- **Two Player Game**: Turn-based gameplay
- **Random Dice Roll**: 1-6 dice mechanics  
- **File Handling**: Player data saved to text file
- **Console Graphics**: ASCII art board display
- **Win Condition**: First to reach square 100

## 🚀 Quick Start
```bash
# Compile and run
g++ "Snake-Ladder Game.cpp" -o snake_ladder
./snake_ladder
```

## 🎯 How to Play
1. **Players take turns** rolling dice
2. **Climb ladders** for shortcuts up
3. **Slide down snakes** when landed on
4. **First to square 100 wins**

## 🛠️ Technical Details
- **Language**: C++
- **Graphics**: Console-based ASCII art
- **Storage**: Text file for game data
- **Platform**: Windows (uses windows.h)
